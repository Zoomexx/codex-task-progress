# Codex 任务进度 · v0.4.2

一个只读的 macOS 悬浮任务面板。它从本机 Codex 会话日志读取任务状态，在桌面上用紧凑的“进行中 / 已完成”面板展示任务、步骤、耗时和 token 统计；不修改 Codex 会话，也不执行账户操作。

## 功能说明

### 1. 任务发现与状态

- 读取 `~/.codex/sessions` 和 `~/.codex/session_index.jsonl`。
- 任务名称优先使用 Codex 对话框名称；没有名称时回退为用户消息或“未命名任务”。
- 自动识别进行中、等待中、已完成、已中断和空闲状态。
- 处理时长以当前任务的 `task_started` 为边界；长会话在边界不在日志尾部时，以终止事件后的首个新工作/用户事件校准，避免把会话创建时间误当作当前任务时长。
- 按最近活动时间排序，并过滤内部 `guardian_review` 记录。

### 2. 主面板

- 进行中始终位于上方，已完成始终位于下方。
- 每个分区显示最近的一项，其余任务通过“其余 N 项”进入详情窗口。
- 面板为紧凑的无边框圆角窗口，不使用滚动条，避免任务内容被上下滑动截断。
- 默认半透明，鼠标悬停时恢复不透明；拖动、置顶和跨桌面显示保持不变。

### 3. 任务交互

- 点击任务行，通过 `codex://threads/<session_id>` 打开对应 Codex 对话。
- 深链不可用时，回退为激活 Codex/ChatGPT，最后才定位到对应本地日志文件。
- 检测到待授权或待批准调用时，面板显示提示并自动显示；状态解除后提示自动消失。

### 4. 更多任务详情

- 点击“其余 N 项”打开独立详情窗口。
- 详情显示任务名称、状态、已处理时间、当前步骤、本轮 token 和待授权信息。
- 鼠标离开主面板与详情窗口后，详情窗口自动隐藏；主面板不受影响。

### 5. Token 统计口径

- 任务行的“本轮消耗约”以对应会话日志的 `total_token_usage` 为基础，减去该任务开始前的基线，只展示本轮新增量。
- 详情页的“累计已消耗约”直接读取各日志文件最新累计快照，并按日志文件去重，不把已完成任务的本轮增量相加。
- 日志文件是并行任务的隔离边界；多个任务同时运行时不会串用基线或重复累计。
- 这些数字是本地日志估算，不等同于 OpenAI 账单。

### 6. 底部运行状态动画

- 面板底部空白区显示一条低对比度横向运行线，仅在存在进行中/等待中任务且空间足够时显示。
- 动画只移动一个图层，使用变换而不是改变宽高，不会推动或遮挡任务文字。
- 普通任务刷新不会重置动画；只有状态、尺寸、颜色或系统“减少动态效果”设置变化时才重新配置。
- 开启 macOS“减少动态效果”后，运行线保持静态提示。

### 7. 菜单栏剩余用量

- 使用官方 Codex App Server 的只读 `account/rateLimits/read` 和 `account/rateLimits/updated`。
- 按 `windowDurationMins` 识别约 300 分钟的 5 小时窗口和约 10080 分钟的 7 天窗口，不按数组顺序猜测。
- 事件到达时刷新；没有事件时每 10 秒最多补读一次；断线重连时保留最近有效快照并显示同步状态。
- 菜单栏显示 5 小时/7 天剩余比例、重置时间、最后同步时间和可用的会话 token 摘要。
- 读取链路不创建 `thread/start`、`turn/start` 或模型回合。

### 8. 单实例与可靠性

- 使用单实例锁，确保只有一个状态栏项目、一个同步服务和一个任务面板。
- App Server 连接、事件订阅、补读和重连均由同一用量同步服务管理。
- 构建支持临时输出目录，便于先编译验收，再替换正式应用。

## 构建与运行

要求 macOS 和 Swift 编译器，不需要第三方依赖：

```bash
./build-app.sh
open CodexTaskProgress.app
```

构建临时版本而不覆盖默认输出：

```bash
CODEX_TASK_PROGRESS_BUILD_APP_DIR=/private/tmp/CodexTaskProgress-preview.app ./build-app.sh
```

解析器冒烟测试：

```bash
cache=$(mktemp -d /private/tmp/codex-task-progress-module-cache.XXXXXX)
swiftc Sources/UsageSnapshot.swift Sources/OfficialUsageClient.swift \
  Tests/UsageSyncParserSmoke.swift -module-cache-path "$cache" \
  -o /private/tmp/UsageSyncParserSmoke
/private/tmp/UsageSyncParserSmoke
```

## 数据来源与隐私边界

- 任务数据只来自当前用户本机的 Codex 会话日志。
- 剩余用量只读本机 Codex App Server 的限额响应；状态栏以官方限额快照为准，任务详情 token 以本地日志为准。
- 不上传任务标题、日志正文或账户数据，不执行网页或账户操作，不读取或保存 Cookie、认证 Token、账户标识、截图、千川文件或备份包。
- 不通过发送聊天消息、创建 Codex 任务或调用模型刷新额度。
