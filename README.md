# codex任务进度

一个只读的 macOS 悬浮任务面板：从本机 `~/.codex/sessions` 会话日志和 `~/.codex/session_index.jsonl` 读取 Codex 对话名称、状态和最近明细，在所有桌面上显示“进行中/已完成”任务进度。

## 功能

- 进行中始终显示在上方，已完成始终显示在下方；每栏默认显示最近任务，其余任务通过“更多”窗口查看。
- 任务名称优先使用 Codex 对话框名称（例如“日常沟通”“营销侧”），小字显示当前步骤、事件和耗时。
- 主面板约 180×165，默认半透明，鼠标移入变为不透明；鼠标移开后“更多任务”窗口自动关闭。
- 点击任务可打开 Codex；找不到应用时回到对应的本地日志文件位置。
- 仅解析本地日志，不连接 Codex app-server，不上传任务标题或日志内容，也不需要 API Key。

## 构建与运行

```bash
bash build-app.sh
open CodexTaskProgress.app
```

要求 macOS 和 Swift 编译器。构建脚本使用系统 Cocoa 框架，不安装第三方依赖。

## 数据边界

本程序只读取当前用户本机的 Codex 会话日志；它不会执行账户操作、修改网页或上传数据。

> 说明：本仓库沿用此前桌面版的 Swift 实现，源文件还保留菜单栏剩余用量模块，便于与同系列程序保持一致；本仓库的定位和说明聚焦于任务进度悬浮窗。
